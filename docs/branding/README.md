# Branding

Original artwork made for Hopmon Native. It contains no artwork from the game.

| File | What it is |
|---|---|
| `../banner.png` | README banner, 2560×640 (shown at 1280×320) |
| `banner.svg` | Banner source. The text uses the [Inter](https://rsms.me/inter/) font (SIL Open Font License); install it before editing or re-exporting. |
| `icon.svg` | Program icon, used for sizes 40 px and up |
| `icon_small.svg` | Simplified icon for 16–32 px (no glow or sparkle, bolder outline) |
| `../../res/hopmon_native.ico` | Windows icon (16, 20, 24, 32, 40, 48, 64, 128 and 256 px), built into `HopmonNative.exe` |

The crystal uses the colour of the game's crystals (`#FF9D9F`), shaded the way the game's lighting
shades it.
